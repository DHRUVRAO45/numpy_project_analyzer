# NumPy Analyzer
NumPy Analyzer is a menu-driven Python program that uses NumPy to create and analyze arrays. It lets users perform common array operations and view basic statistics through a simple text menu.
## Features
1. **Create NumPy arrays** — create 1D, 2D, or 3D arrays.
2. **Indexing and slicing** — access array elements and slice 1D arrays.
3. **Mathematical operations** — add, subtract, multiply, divide, calculate dot products, and perform matrix multiplication.
4. **Combine or split arrays** — combine 1D arrays or split a 1D array into two parts.
5. **Search, sort, and filter** — search for values, sort an array, or display values greater than a chosen number.
6. **Statistics** — calculate sum, mean, median, standard deviation, variance, minimum, maximum, percentiles, and optionally correlation.
7. **Menu-driven interface** — choose an operation from the main menu and exit when finished.

## Requirements

- Python 3
- NumPy

## Installation

Install NumPy from PowerShell or your terminal:

```bash
python -m pip install numpy
```

## How to Run

Save the program as `Numpy_Analyzer.py`. Open PowerShell in the folder containing the file and run:

```powershell
python Numpy_Analyzer.py
```

Follow the on-screen menu and enter the requested values.

## Example Menu

```text
========== NUMPY ANALYZER ==========
1. Create a NumPy Array
2. Indexing and Slicing
3. Mathematical Operations
4. Combine or Split Arrays
5. Search, Sort, or Filter
6. Aggregates and Statistics
7. Exit
```

## Notes

- Create an array before selecting an operation that needs one.
- Enter numeric values separated by spaces when prompted.
- For 2D and 3D arrays, provide the number of values requested by the program.
- Some operations are limited to 1D or 2D arrays, as explained by the program.
